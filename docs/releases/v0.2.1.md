# AOS 0.2.1

本版增加 Agent 的网络发现入口，保持现有 Topic、Service、Action 和 NodeCard 通信契约。
运行 0.2.0 的节点不需要为了这些查询更换 SDK。

- `graph snapshot`：一次取得节点与端点归属、类型/hash、说明、副作用与生命周期状态。
- `graph watch`：发送初始快照和按实例 ID 合并的增量；支持节点加入、端点更新、退出及恢复。
- `graph wait`：在一个总时限内等待指定节点或能力，保留超时前的最后观察。
- 说明读取使用有界并发，区分待查询、不可读、同名冲突和成功读取；失败不等于节点离线。
- Skill 提供发现、选择和缓存合并流程；按需读取完整接口，避免每次遍历所有 NodeCard 和 schema。

发现范围仍由 Router 连通性、domain 和权限决定。业务健康与授权需要独立证据。
持续观察允许合并瞬时变化；它不是持久事件日志，也不自行唤醒未运行的 Agent。
完整字段、默认值和边界见[网络发现](../discovery.md)与安装后命令 schema。
