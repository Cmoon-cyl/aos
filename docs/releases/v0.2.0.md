# AOS 0.2.0

2026-10-22 · 三平台完整发行

0.2.0 将 AOS 的 Topic、Service、Action 与发现能力扩展为可部署的应用平台。
每个平台包包含原生 CLI、CPython 3.11 SDK wheel、固定 Zenoh 1.10.1 Router、
配置、接口、示例、示例安装器、使用文档、上游许可与来源清单。
Windows ZIP 同样提供完整功能和 Router 随附 DLL，不需要在目标机编译 Rust。

## 主要能力

- Graph 与 NodeCard 发现；完整 JSON Interface、Schema 校验和类型 hash。
- Topic QoS、显式次数/持续发布、过滤、字段选择、条件与脚本 hook、频率和带宽统计。
- Service 单次请求与显式重复调用；Action 受理、反馈、协作取消、终态结果。
- 配置优先级、精确 remapping、Clock/Timer/Rate、参数与生命周期。
- 安装包索引、run/launch、依赖就绪、有限重启和有界退出。
- MCAP bag 录制、检查、恢复、暂停与回放。
- mTLS、默认拒绝 ACL、本机 peer/gossip、每机 Router 与显式跨 Router 连接。
- SQLite MemoryServer：幂等写入、查询、快照导出、参数和生命周期；独立请求观察器。

## 平台实现

- Windows 采用 Job Object 管理本次启动的进程树，使用原生管道、控制台输出和文件处理；补齐 hook、doctor、bag 和 Memory 的原生行为与测试。
- macOS 直接执行程序或显式解释器；无效可执行文本返回启动错误，不隐式进入 shell，并清理此前启动的进程。
- 修复 TLS 到期任务早于连接对象初始化完成而漏关连接的竞态；拒绝已经到期的新连接，保留原有证书到期测试期限。

## 平台与运行环境

发行包提供 macOS arm64、Linux x86_64 GNU 和 Windows x86_64 MSVC 原生程序。
Python SDK 的验证范围为 CPython 3.11。Windows 需要 Microsoft Visual C++ v14 x64 运行库。
Linux wheel 不具有 manylinux 或 musl 兼容承诺；macOS wheel 的部署标签不等于最低系统版本实测。

每个完整包的 `manifest.json` 记录程序构建来源、Router 来源和逐文件 SHA256。
Release 同时提供 `.sha256` 和 `SHA256SUMS`，下载后按安装指南核对。

## 升级时注意

默认 peer 可以先于 Router 打开，随后后台连接；Context 打开不能作为业务就绪判据。
开发 Router 默认监听网络接口，Windows 使用单独 IPv4 配置。安全部署使用显式 profile，失败不退回明文。

Topic pub 仍默认一次，但默认不等待订阅者；需要等待时显式设置
`wait_for_subscribers` 与 `match_timeout`。Service 不自动重试，普通 Action 结果等待超时不自动取消。
部署环境可以覆盖 Context 的程序初值，需要最高优先级时使用明确的 CLI 配置层。
接口限制、错误分类和输出变化见[迁移指南](../platform/migration-0.2.md)。
